# 🧟 The Night of the Zombies (TNOTZ)


Benvenuto in **The Night of the Zombies**, un'avventura testuale survival scritta interamente in C++. Il gioco ti catapulterà nel bel mezzo di un'improvvisa apocalisse zombie direttamente dal comfort del tuo appartamento. Riuscirai a sopravvivere alla prima notte?

---

## 🕹️ Caratteristiche del Progetto

*   **🎮 Gameplay Survival Testuale:** Prendi decisioni critiche in frazioni di secondo. Ogni scelta può portarti alla salvezza o a una fine orribile.
*   **⚔️ Sistema di Combattimento Procedurale:** Affronta le minacce usando un sistema basato su probabilità reali e differenziazione del danno in base all'arma scelta (torcia, mazza da baseball o coltello da caccia).
*   **🎨 Grafica e Interfaccia ASCII:** Un look squisitamente retrò che sfrutta l'arte ASCII direttamente nel terminale per l'introduzione e le schermate di Game Over.
*   **🛠️ Architettura Procedurale Pulita:** Il codice segue una struttura logica sequenziale e procedurale, ideale per lo studio delle basi di programmazione in C++.
*   **🧠 Gestione dell'Input Robusta:** Sistema ottimizzato per prevenire i bug di salto del buffer del terminale (`std::cin`), garantendo un'esperienza di gioco fluida.

---

## 🚀 Come Avviare il Gioco

### Requisiti
*   Un compilatore C++ (GCC, Clang o MSVC)

### Compilazione (da Terminale)
Puoi compilare il codice principale utilizzando un qualsiasi terminale con la riga di comando:

```bash
g++ -std=c++11 main.cpp -o tnotz
```

### Esecuzione
```bash
./tnotz      # Su Linux/macOS
tnotz.exe    # Su Windows
```

## 📖 Storia e Ambientazione

Ti trovi nel tuo appartamento, pronto per andare a dormire, quando delle urla strazianti attirano la tua attenzione alla finestra. Un vecchio viene aggredito in cortile da due figure frenetiche. Da questo momento in poi, il destino è nelle tue mani. Esplora i bivi narrativi, raccogli le armi e cerca di fuggire dalla città prima che sia troppo tardi.
